MR Video Deployment Guide - Hostinger VPS

1. Server requirements
   - Ubuntu VPS
   - Node.js 22 LTS or newer
   - PostgreSQL or external Prisma Postgres
   - Nginx
   - PM2
   - Git

2. Install packages
   sudo apt update
   sudo apt install -y nginx git curl
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
   sudo apt install -y nodejs
   sudo npm install -g pm2

3. Clone project
   git clone YOUR_REPO_URL mr-video
   cd mr-video
   npm ci

4. Create .env
   DATABASE_URL=
   JWT_SECRET=
   ADMIN_USERNAME=
   ADMIN_PASSWORD=
   CLOUDINARY_CLOUD_NAME=
   CLOUDINARY_UPLOAD_PRESET=
   CLOUDINARY_API_KEY=
   CLOUDINARY_API_SECRET=

5. Database
   npm run build
   npx prisma migrate deploy
   npx tsx prisma/seed.ts

6. Build app
   npm run build

7. Run with PM2
   pm2 start npm --name mr-video -- start
   pm2 save
   pm2 startup

8. Nginx config
   sudo nano /etc/nginx/sites-available/mr-video

   server {
     listen 80;
     server_name your-domain.com www.your-domain.com;

     client_max_body_size 32m;

     location / {
       proxy_pass http://127.0.0.1:3000;
       proxy_http_version 1.1;
       proxy_set_header Upgrade $http_upgrade;
       proxy_set_header Connection 'upgrade';
       proxy_set_header Host $host;
       proxy_set_header X-Real-IP $remote_addr;
       proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       proxy_set_header X-Forwarded-Proto $scheme;
       proxy_cache_bypass $http_upgrade;
     }
   }

   sudo ln -s /etc/nginx/sites-available/mr-video /etc/nginx/sites-enabled/mr-video
   sudo nginx -t
   sudo systemctl reload nginx

9. SSL
   sudo apt install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d your-domain.com -d www.your-domain.com

10. Production checks
   npm run lint
   npm run build
   pm2 logs mr-video
   curl -I https://your-domain.com

11. Updating deploy
   git pull
   npm ci
   npx prisma migrate deploy
   npm run build
   pm2 restart mr-video

12. Notes
   - Use strong JWT_SECRET.
   - Keep Cloudinary upload preset restricted to needed formats.
   - Ads load from DB only.
